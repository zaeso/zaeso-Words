# Classic Word Search (Java)

[![CI](https://github.com/zaeso/zaeso-Words/actions/workflows/ci.yml/badge.svg)](https://github.com/zaeso/zaeso-Words/actions/workflows/ci.yml)

Десктопная игра-головоломка на Java 8+ с графическим интерфейсом Swing и отладочным консольным режимом. Проект разделён на пакеты `model`, `generator`, `config`, `session`, `play`, `score`, `result`, `dictionary`, `daily` и `ui`.

## Запуск готового JAR

Скачайте `zaeso-words-1.1.5.jar` и `run-game.bat` из [последнего релиза](https://github.com/zaeso/zaeso-Words/releases/latest) в одну папку. Требуется только Java 8+ (достаточно JRE), Maven не нужен.

Запуск двойным кликом по `run-game.bat` или вручную:

```bash
java -jar zaeso-words-1.1.5.jar
```

Без аргументов открывается графический интерфейс. Для отладочного консольного режима добавьте флаг:

```bash
java -jar zaeso-words-1.1.5.jar --console
```

JAR уже содержит все зависимости, поэтому запуск не требует отдельной настройки classpath.

## Сборка из исходников

Требуется JDK 8+ и Maven. Из корневой папки проекта:

```bash
mvn package
java -jar target/zaeso-words-1.1.5.jar
```

`mvn verify` дополнительно запускает все тесты и создаёт исполняемый JAR.

## Графический интерфейс

- Главное меню: «Играть», «Сетка дня», «Статистика», «Настройки», «Рекорды», «Выход».
- «Сетка дня» запускает ежедневную головоломку с фиксированными параметрами, а «Статистика» показывает лучший счёт, серию дней и число найденных слов.
- На одном экране настроек выбираются сложность, категория, размер сетки и длительность раунда. Число подсказок и минимум слов берутся из профиля сложности, а выбранные параметры проверяются до генерации и сохраняются между запусками. Ежедневная сетка не зависит от этих настроек.
- Слова находятся выделением мыши по строке, столбцу или диагонали; ввод с клавиатуры не используется.
- Список слов виден сразу. Найденные слова отмечаются разными цветами, а их буквы подсвечиваются на сетке тем же цветом.
- Кнопка «Подсказка» открывает длину, первую букву и направление ненайденного слова, а клетка с первой буквой подсвечивается зелёным.
- «Рекорды» открывает полную таблицу результатов текущего режима, а «Экспорт CSV» сохраняет всю историю игр в файл для табличного редактора.
- Игра бесконечная: после раунда можно начать следующий, не теряя накопленные очки. Экран итогов показывает счёт раунда, его разбивку и общий счёт.
- Тема оформления («Классика», «Океан», «Лес», «Тёмная»), звуковые эффекты и анимация подсветки найденных букв настраиваются на том же экране и сохраняются между запусками. Оформление и звук не влияют на игровую логику `GameSession`.

Игровая логика у `GameSession` общая для GUI и консоли, поэтому правила проверки слов, подсказки, таймер и очки в обоих режимах совпадают.

## Алгоритм генерации

1. Нормализовать словарь: перевести слова в верхний регистр, убрать посторонние символы и дубликаты.
2. Отсеять слова, длина которых больше максимального размера сетки.
3. Создать пустую сетку выбранного размера.
4. Перемешать слова и размещать более длинные раньше.
5. Для каждого слова случайно выбрать начальную клетку и одно из 8 направлений: горизонталь, вертикаль или диагональ.
6. Проверить, что последняя буква попадает внутрь сетки и что занятые клетки либо пусты, либо содержат ту же букву.
7. Если проверка успешна — записать слово в сетку. Иначе повторить попытку.
8. Если удалось разместить не менее 10 слов — заполнить пустые клетки случайными русскими буквами.
9. Если не получилось, начать генерацию заново. После ограниченного числа перезапусков сообщить об ошибке.

Слова не повторяются, потому что словарь очищается через `distinct()`. Пересечения разрешены только на одинаковых буквах. Генератор использует ограниченное число попыток, поэтому при неудачной случайной раскладке может сообщить, что размещение не удалось; тогда следует расширить словарь или повторить генерацию. Для воспроизводимости можно создать генератор с seed: `new GridGenerator(42L)`. Одинаковые seed и входные данные дают одинаковую сетку.

## Уровни сложности

Перед началом игры можно выбрать сложность и категорию слов. Все параметры сложности хранятся в `GameConfig`, а готовые наборы заданы в `Difficulty`:

| Уровень | Сетка по умолчанию | Минимум слов | Время | Подсказки |
| --- | --- | --- | --- | --- |
| Лёгкий | 10×10 | 8 | 7 минут | 3 |
| Обычный | 10×10 | 10 | 5 минут | 2 |
| Сложный | 12×10 | 12 | 4 минуты | 1 |

Сложность можно ввести номером (`1`–`3`) или названием в любом регистре. В GUI сложность, категория, размер сетки и длительность выбираются на одном экране: при смене сложности размер и время подставляются из её профиля, но остаются доступными для изменения. В консольном режиме те же параметры запрашиваются по очереди, а Enter сохраняет значение по умолчанию. Генератор и таймер получают параметры из одного и того же `GameConfig`, поэтому для разных режимов не требуется отдельная логика.

## Сохранение параметров

Выбранные сложность, категория, размер сетки и длительность сохраняются в `~/.zaeso-words/settings.properties` и восстанавливаются при следующем запуске GUI и консоли. Перед генерацией `GameSettings` проверяет допустимый размер, длительность от 1 до 60 минут и наличие нужного числа слов в категории. При ошибке игра показывает пояснение и не начинает раунд. Минимум слов и число подсказок по-прежнему задаются профилем сложности.

## Сетка дня и статистика

Кнопка «Сетка дня» открывает ежедневную головоломку. Её параметры зафиксированы в `DailyPuzzle`: обычная сложность, сетка 10×10, слова из категории «Все русские слова» и 5 минут. Seed вычисляется из календарной даты по алгоритму SplitMix64, поэтому одна и та же дата даёт одинаковую сетку у всех игроков, а сохранённые настройки на неё не влияют. Результаты ежедневных игр сохраняются как обычно, но с названием сложности «Ежедневная»; поэтому они не смешиваются с обычными рекордами.

Личная статистика `DailyStatistics` считается из сохранённых `GameResult`: лучший счёт, текущая серия дней, число дней с ежедневными играми и суммарное число найденных слов. Серия продолжается, если последняя сетка пройдена сегодня или вчера, и прерывается после пропущенного дня.

## Категории и словари

Словари вынесены в ресурсы `src/main/resources/dictionaries/`. Индекс `categories.txt` задаёт отображаемое название и файл словаря в формате `Название|файл.txt`, по одной категории на строку. Сейчас доступны «Технологии» (по умолчанию), «Животные», «Космос», «Природа», «Еда» и «Все русские слова».

Категория «Все русские слова» содержит более миллиона словоформ длиной от 3 до 12 букв из открытого списка [danakt/russian-words](https://github.com/danakt/russian-words) (MIT). Для сетки игра берёт из них слова длиной до 10 букв: более длинные почти не помещаются вместе с остальными. Выборка стратифицирована по длине, поэтому в ней много коротких слов, а диагональные направления размещаются чаще прямых. Для больших словарей в индексе указывается режим `stream`: `Все русские слова|all-russian.txt|stream`. В этом режиме файл не загружается в память целиком — игра строит случайную выборку и каждый раунд берёт из неё новые слова, поэтому сетка получает случайные слова со всего списка.

Новая категория добавляется без изменения Java-кода: достаточно положить файл со словами в `dictionaries/` и добавить строку в `categories.txt`. Слова в файле разделяются переводами строк; пустые строки и строки, начинающиеся с `#`, игнорируются. `WordCategory` приводит слова к верхнему регистру и убирает дубликаты.

Категория выбирается в настройках GUI или в консольном режиме номером либо названием. `WordBank` оставлен как словарь категории по умолчанию. Если в выбранном словаре не хватает подходящих слов для сетки и сложности, `GridGenerator.generateChecked` возвращает `GenerationResult` с понятным сообщением: сколько слов нужно, сколько подходит и сколько всего было во входном списке.

## Таймер

Длительность игры по умолчанию берётся из выбранного уровня сложности, но её можно изменить в настройках GUI или при запуске консольного режима. В GUI оставшееся время показывается в верхней панели, в консоли — в приглашении ко вводу и в предупреждениях за 60, 30 и последние 10 секунд. Когда время заканчивается, раунд завершается и показывает результаты: сколько слов найдено, сколько времени затрачено и сколько очков получено. Для тестов и нестандартных режимов лимит можно передать напрямую через `ConsoleGame(puzzle, scanner, Duration)` или через `GameConfig`.

## Очки

Очки считает `ScoreCalculator` — отдельный класс без ввода/вывода, поэтому формула не зависит от консольного форматирования.

**Формула:**

```
очки за слова = сумма стоимости всех букв найденных слов
бонус за время = 2 × оставшиеся секунды, только если найдены все слова
штраф за ошибки = 5 × число ошибочных попыток
штраф за подсказки = 50 × число подсказок
итог = max(0, очки за слова + бонус за время − штрафы)
```

Чем реже буква встречается в русских словах, тем больше она приносит:

| Очки за букву | Буквы |
| --- | --- |
| 10 | О, Е, А, И, Н, Т, С, Р, В, Л |
| 15 | К, М, Д, П, У, Я |
| 20 | Ы, Ь, Г, З, Б, Ч |
| 25 | Й, Х, Ж, Ш, Ю, Ц, Щ, Э, Ф |
| 30 | Ъ, Ё |

Ошибочной считается попытка ввести слово, которого нет в списке, или повтор уже найденного слова. Подсказка дополнительно отнимает 30 секунд игрового времени. После раунда выводится счёт и разбивка: буквы, время, ошибки и подсказки. В бесконечном режиме сумма очков за раунды показывается как общий счёт. Счёт также сохраняется в результатах и используется для сортировки таблицы рекордов.

## Подсказки

Во время игры кнопка «Подсказка» в GUI или команда `HINT`/`ПОДСКАЗКА` в консоли открывает длину, первую букву и направление одного из ненайденных слов. В GUI клетка с первой буквой дополнительно подсвечивается зелёным. Слово целиком не показывается, а координаты не раскрываются. Каждая подсказка отнимает 30 секунд игрового времени. Число подсказок задаётся в `GameConfig` и зависит от сложности; за одно и то же слово штраф повторно не списывается, а после исчерпания лимита игра сообщает об этом и продолжается.

## Результаты и рекорды

Каждая завершённая игра сохраняется в `~/.zaeso-words/results.json`. Запись выполняется атомарно: сначала во временный файл в том же каталоге, затем переименованием на место основного. Если файл повреждён, игра не падает: он переименовывается в резервную копию `results.json.corrupt-<время>`, а игра продолжается с пустой таблицей.

Результат содержит время завершения, сложность, размер сетки, число найденных и общих слов, затраченное время, число подсказок, итоговый счёт с разбивкой и причину завершения. Кнопка «Рекорды» показывает полную таблицу для текущих сложности, категории и размера сетки: сначала больше очков, затем больше найденных слов, затем меньше затраченное время. Таблицу можно сортировать по столбцам.

Кнопка «Экспорт CSV» сохраняет всю историю игр в выбранный файл. Формат рассчитан на табличные редакторы: UTF-8 с BOM, разделитель `;`, столбцы «Дата», «Сложность», «Сетка», «Найдено», «Всего слов», «Процент», «Время (с)», «Подсказки», «Очки» и «Причина». Экспорт только читает `results.json` и не меняет сохранённые записи.

## Ввод

В GUI слово выделяется мышью на сетке. В консольном режиме слово вводится целиком. Недопустимый размер сетки не завершает программу: игра сообщает об ошибке и запрашивает высоту и ширину заново. Пустая строка, слова с латиницей или другими символами и слишком длинные слова отклоняются с пояснением, после чего игра продолжается. `EXIT` принимается в любом регистре.

## Тестирование

```bash
mvn test
```

147 тестов проверяют:

- параметры и валидацию `GameConfig`;
- три уровня сложности, разбор номера и названия, значения по умолчанию;
- загрузку категорий из индекса ресурсов и достаточность слов в каждом словаре;
- выбор категории в консольном режиме и понятные ошибки генератора при нехватке слов;
- допустимые размеры, длительность и перенос минимума слов с подсказками в `GameSettings`;
- сохранение и восстановление параметров, повреждённый файл и значения по умолчанию;
- стабильный seed ежедневной сетки по дате, фиксированные параметры и одинаковую сетку при повторной генерации;
- расчёт личной статистики: лучший счёт, серию дней, пропуски и сумму найденных слов;
- воспроизводимость раунда при одинаковом seed и различие раундов при разных seed;
- независимое сохранение темы, звука и анимаций рядом с игровыми параметрами;
- разные цвета найденных слов и отдельную зелёную подсветку клетки подсказки;
- случайную выборку слов из полного словаря, перекос в сторону коротких слов и подсчёт подходящих слов без загрузки всего файла;
- выбор длительности в консоли и сохранённые значения по умолчанию;
- использование лимита времени из выбранной сложности;
- наличие всех 8 направлений размещения слов и приоритет диагоналей;
- размещение слова в каждом из 8 направлений;
- отказ при выходе слова за границы сетки без изменения сетки;
- пересечение только на одинаковых буквах и отказ при несовпадении;
- воспроизводимость раскладки при одинаковом seed;
- нормализацию, дедупликацию и фильтрацию словаря;
- заполнение всей сетки русскими буквами и соответствие размещённых слов клеткам;
- поведение при нехватке слов или свободного места;
- неизменяемость списка размещений в модели `Puzzle`;
- отсчёт, остановку, истечение и форматирование времени в `GameTimer`;
- приём правильного слова и досрочное завершение игры по таймеру;
- повторный запрос размера при ошибке и завершение при конце ввода;
- пустой ввод, латиницу, слишком длинное слово, `EXIT` в любом регистре и повтор слова;
- подсказки: первую букву и направление, штраф времени, лимит и отсутствие повторного штрафа;
- сохранение результатов, атомарную запись, повреждённый JSON и полную таблицу рекордов;
- экспорт истории в CSV с заголовком, экранированием и UTF-8 BOM;
- сортировку рекордов по размеру сетки, сложности и очкам;
- стоимость редких и частых букв, сумму очков за слово;
- формулу очков: бонус за время, штрафы за ошибки и подсказки, нижнюю границу нуля;
- общую `GameSession`: проверку слов, ошибки, команды, подсказки и завершение раунда;
- загрузку категорий из ресурсов, выбор словаря и сообщения генератора о нехватке слов.

Тесты запускаются автоматически в GitHub Actions при каждом push в `main` и при создании pull request.

## Структура

- `game.model` — направления, размещение слова и модель сетки.
- `game.config` — профили сложности, параметры `GameSettings` и их сохранение в `SettingsStore`.
- `game.generator` — алгоритм случайной генерации и `RoundGenerator` с воспроизводимым seed.
- `game.session` — общая игровая логика для GUI и консоли.
- `game.play` — отладочный консольный цикл и таймер.
- `game.score` — стоимость букв и формула очков.
- `game.result` — модель результата, JSON-хранилище, полная таблица рекордов и экспорт истории в CSV.
- `game.dictionary` — категории и загрузка словарей из ресурсов; `WordBank` — набор по умолчанию.
- `game.daily` — ежедневная сетка по seed даты и личная статистика.
- `game.ui` — Swing-интерфейс: окно, меню, сетка и экран итогов.
- `game.Main` — запуск GUI или консольного режима по флагу `--console`.
- `src/test/java` — тесты JUnit 5.
- `.github/workflows/ci.yml` — конфигурация CI.
