# Classic Word Search (Java)

[![CI](https://github.com/zaeso/zaeso-Words/actions/workflows/ci.yml/badge.svg)](https://github.com/zaeso/zaeso-Words/actions/workflows/ci.yml)

Консольная игра-головоломка на Java 17+. Проект разделён на пакеты `model`, `generator`, `config` и `play`.

## Запуск

Из корневой папки проекта:

```bash
javac -encoding UTF-8 -d out src/main/java/game/model/*.java src/main/java/game/generator/*.java src/main/java/game/config/*.java src/main/java/game/play/*.java src/main/java/game/Main.java
java -cp out game.Main
```

Через Maven:

```bash
mvn compile
java -cp target/classes game.Main
```

## Алгоритм генерации

1. Нормализовать словарь: перевести слова в верхний регистр, убрать посторонние символы и дубликаты.
2. Отсеять слова, длина которых больше максимального размера сетки.
3. Создать пустую сетку выбранного размера.
4. Перемешать слова и размещать более длинные раньше.
5. Для каждого слова случайно выбрать начальную клетку и одно из 8 направлений: горизонталь, вертикаль или диагональ.
6. Проверить, что последняя буква попадает внутрь сетки и что занятые клетки либо пусты, либо содержат ту же букву.
7. Если проверка успешна — записать слово в сетку. Иначе повторить попытку.
8. Если удалось разместить не менее 10 слов — заполнить пустые клетки случайными русскими буквами.
9. Если не получилось, начать генерацию заново. После ограниченного числа перезапусков сообщить об ошибке.

Слова не повторяются, потому что словарь очищается через `distinct()`. Пересечения разрешены только на одинаковых буквах. Генератор использует ограниченное число попыток, поэтому при неудачной случайной раскладке может сообщить, что размещение не удалось; тогда следует расширить словарь или повторить генерацию. Для воспроизводимости можно создать генератор с seed: `new GridGenerator(42L)`. Одинаковые seed и входные данные дают одинаковую сетку.

## Уровни сложности

Перед началом игры можно выбрать уровень сложности. Все параметры хранятся в `GameConfig`, а готовые наборы заданы в `Difficulty`:

| Уровень | Сетка по умолчанию | Минимум слов | Время | Подсказки |
| --- | --- | --- | --- | --- |
| Лёгкий | 10×10 | 8 | 7 минут | 3 |
| Обычный | 10×10 | 10 | 5 минут | 2 |
| Сложный | 12×10 | 12 | 4 минуты | 1 |

Сложность можно ввести номером (`1`–`3`) или названием в любом регистре. Пустой ввод выбирает обычный уровень. После выбора профиля можно согласиться с размером сетки по умолчанию (Enter) или ввести другой допустимый размер. Генератор и таймер получают параметры из одного и того же `GameConfig`, поэтому для разных режимов не требуется отдельная логика.

## Таймер

Длительность игры берётся из выбранного уровня сложности. Оставшееся время показывается в приглашении ко вводу, а также в виде предупреждений за 60, 30 и последние 10 секунд. Когда время заканчивается, игра завершается и выводит результаты: сколько слов найдено и сколько времени затрачено. Для тестов и нестандартных режимов лимит можно передать напрямую через `ConsoleGame(puzzle, scanner, Duration)` или через `GameConfig`.

## Ввод

Недопустимый размер сетки не завершает программу: игра сообщает об ошибке и запрашивает высоту и ширину заново. Пустая строка, слова с латиницей или другими символами и слишком длинные слова отклоняются с пояснением, после чего игра продолжается. `EXIT` принимается в любом регистре.

## Тестирование

```bash
mvn test
```

48 тестов проверяют:

- параметры и валидацию `GameConfig`;
- три уровня сложности, разбор номера и названия, значения по умолчанию;
- использование лимита времени из выбранной сложности;
- наличие всех 8 направлений размещения слов;
- размещение слова в каждом из 8 направлений;
- отказ при выходе слова за границы сетки без изменения сетки;
- пересечение только на одинаковых буквах и отказ при несовпадении;
- воспроизводимость раскладки при одинаковом seed;
- нормализацию, дедупликацию и фильтрацию словаря;
- заполнение всей сетки русскими буквами и соответствие размещённых слов клеткам;
- поведение при нехватке слов или свободного места;
- неизменяемость списка размещений в модели `Puzzle`;
- отсчёт, остановку, истечение и форматирование времени в `GameTimer`;
- приём правильного слова и досрочное завершение игры по таймеру;
- повторный запрос размера при ошибке и завершение при конце ввода;
- пустой ввод, латиницу, слишком длинное слово, `EXIT` в любом регистре и повтор слова.

Тесты запускаются автоматически в GitHub Actions при каждом push в `main` и при создании pull request.

## Структура

- `game.model` — направления, размещение слова и модель сетки.
- `game.config` — параметры игры и профили сложности.
- `game.generator` — алгоритм случайной генерации.
- `game.play` — игровой цикл, таймер и вывод сетки.
- `game.Main` — запуск программы и выбор размера.
- `src/test/java` — тесты JUnit 5.
- `.github/workflows/ci.yml` — конфигурация CI.
