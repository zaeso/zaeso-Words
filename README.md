# Classic Word Search (Java)

Консольная игра-головоломка на Java 17+. Проект разделён на пакеты `model`, `generator` и `play`.

## Запуск

Из корневой папки проекта:

```bash
javac -encoding UTF-8 -d out src/main/java/game/model/*.java src/main/java/game/generator/*.java src/main/java/game/play/*.java src/main/java/game/Main.java
java -cp out game.Main
```

## Алгоритм генерации

1. Нормализовать словарь: перевести слова в верхний регистр, убрать посторонние символы и дубликаты.
2. Отсеять слова, длина которых больше максимального размера сетки.
3. Создать пустую сетку выбранного размера.
4. Перемешать слова и размещать более длинные раньше.
5. Для каждого слова случайно выбрать начальную клетку и одно из 8 направлений: горизонталь, вертикаль или диагональ.
6. Проверить, что последняя буква попадает внутрь сетки и что занятые клетки либо пусты, либо содержат ту же букву.
7. Если проверка успешна — записать слово в сетку. Иначе повторить попытку.
8. Если удалось разместить не менее 10 слов — заполнить пустые клетки случайными русскими буквами.
9. Если не получилось, начать генерацию заново. После ограниченного числа перезапусков сообщить об ошибке.

Слова не повторяются, потому что словарь очищается через `distinct()`. Пересечения разрешены только на одинаковых буквах. Генератор использует ограниченное число попыток, поэтому при неудачной случайной раскладке может сообщить, что размещение не удалось; тогда следует расширить словарь или повторить генерацию.

## Таймер

На игру отводится 5 минут. Оставшееся время показывается в приглашении ко вводу, а также в виде предупреждений за 60, 30 и последние 10 секунд. Когда время заканчивается, игра завершается и выводит результаты: сколько слов найдено и сколько времени затрачено. Длительность игры по умолчанию задаётся в `ConsoleGame` и может быть передана через конструктор `ConsoleGame(puzzle, scanner, Duration)`.

## Структура

- `game.model` — направления, размещение слова и модель сетки.
- `game.generator` — алгоритм случайной генерации.
- `game.play` — игровой цикл, таймер и вывод сетки.
- `game.Main` — запуск программы и выбор размера.
